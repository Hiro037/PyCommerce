# Интернет-магазин

Этот проект реализует функционал для работы с категориями и продуктами в интернет-магазине, включая создание объектов, подсчёт количества и загрузку данных из JSON файла.

## Реализованный функционал

1. **Классы `Product` и `Category`**:
   - Класс `Product`: содержит атрибуты `name`, `description`, `price`, `quantity`.
   - Класс `Category`: содержит атрибуты `name`, `description`, `products` (список товаров). Также реализованы атрибуты класса для подсчёта категорий и товаров.

2. **Инициализация объектов**:
   - Конструкторы классов инициализируют все атрибуты при создании объекта.
   - Для класса `Category` автоматически обновляются атрибуты класса (`category_count`, `product_count`).

3. **Тесты с `pytest`**:
   - Написаны тесты на корректность инициализации объектов `Product` и `Category`, а также на подсчёт количества продуктов и категорий.

4. **Подгрузка данных из JSON**:
   - Функция для подгрузки данных о категориях и товарах из файла **`products.json`** и создания объектов классов.
