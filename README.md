# Интернет-магазин

Проект предоставляет классы для работы с товарами, категориями и их специализированными типами (смартфоны, газонная трава). 
Реализована логика обновления товаров, контроля целостности данных и генерации отчетов.

## 📦 Основной функционал

### 1. **Класс `Product`**
- Создание товаров с характеристиками: название, описание, цена, количество
- Автоматическое обновление количества при повторном добавлении
- Валидация цены (защита от отрицательных значений и подтверждение понижения цены)
- Переопределение операторов:
  - `__str__` для красивого вывода информации
  - `__add__` для сложения стоимости товаров одного типа

### 2. **Класс `Category`**
- Управление категориями товаров
- Подсчет общего количества товаров и категорий
- Итерация по товарам категории
- Защита от добавления объектов не-товаров

### 3. **Специализированные классы**
- `Smartphone`: добавлены атрибуты:
  - Производительность процессора
  - Модель
  - Объем памяти
  - Цвет
- `LawnGrass`: добавлены атрибуты:
  - Страна-производитель
  - Срок прорастания
  - Цвет

### 4. **Вспомогательные функции**
- `load_data_from_json()`: загрузка данных из JSON-файла с автоматическим созданием категорий и товаров

## 🛠 Тестирование
Реализованы модульные тесты для проверки:
- Корректности инициализации объектов
- Логики обновления цен и количества
- Обработки ошибок при неверных операциях
- Работы операторов сложения
- Валидации типов данных

**Запуск тестов:**
```bash
pytest test_classes.py --html=report.html
```

### Пример использования

```python
from classes import Product, Category

# Создание товара
iphone = Product(
    "iPhone 15", 
    "Флагманский смартфон", 
    120000.0, 
    10
)

# Создание категории
electronics = Category("Электроника", "Гаджеты и устройства")

# Добавление товара в категорию
electronics.add_product(iphone)

# Вывод информации
print(iphone)         # iPhone 15, 120000 руб. Остаток: 10 шт.
print(electronics)    # Электроника, количество продуктов: 10 шт.
```
## Работа с JSON
```python
categories = load_data_from_json("data.json")
for category in categories:
    print(f"Категория: {category.name}")
    for product in category:
        print(f" - {product}")
```
